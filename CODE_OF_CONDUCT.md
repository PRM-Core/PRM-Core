# Code of conduct

PRM Core is built for clinics and the people who work in them. We want this
project to be a welcoming place for everyone who wants to improve it —
developers, clinic staff, designers, translators — regardless of experience,
background or language.

**Expected:** be kind and patient, assume good intent, give specific and
constructive feedback, respect that many contributors write in their second
language.

**Not acceptable:** harassment, insults, discriminatory language, personal
attacks, publishing someone's private information, and — specific to this
project — sharing real patient data anywhere in the project's spaces.

**Enforcement:** maintainers may edit or remove comments, issues and pull
requests that break these rules and may block repeat offenders. Report problems
privately to the maintainers through the contact listed on the repository
owner's GitHub profile.

---

🇵🇱 **Po polsku:** bądźmy dla siebie życzliwi i konkretni. Obraźliwe
zachowanie i publikowanie cudzych danych — w tym prawdziwych danych pacjentów —
nie są akceptowane; opiekunowie mogą usuwać takie treści i blokować autorów.
