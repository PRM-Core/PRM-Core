# Recipes — connecting other systems without code

Short, practical guides for connecting a specific system to PRM Core through the
[lead webhook](../INTEGRATIONS.md#a-lead-webhook-no-code) or the booking webhook,
usually with n8n, Make or Zapier in between.

A good recipe (`docs/recipes/<system>.md`):

1. What it does in one sentence (e.g. "new Typeform response → PRM contact with
   consents and a tag").
2. Prerequisites (accounts, plan limits).
3. Step-by-step setup with the exact field mapping as a table.
4. How to verify it worked (the `warnings` in the webhook response, the contact
   timeline).
5. Screenshots **with demo data only**.
